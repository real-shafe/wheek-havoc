# Wheek Havoc

A campy first-person 3D roguelite. You're a guinea pig escaping a lab, punching your way through robot scientists.

**Play:** https://real-shafe.github.io/wheek-havoc/

- Punch combos, a stunning "Wheek" shout, dash, jump and belly flop
- Science vials grant temporary powers: angel wings, eye lasers, chain lightning, giant mode, popcorn hops, super speed, slow time
- Four sectors, mutations between waves, seeds that carry over between runs, and a boss: Dr. Autoclave

**Controls:** mouse to look, hold click to punch, right-click or Q to shout, Shift to dash, Space to jump, C in mid-air to belly flop.

Single self-contained `index.html` built with Three.js. All sound is generated in the browser.
